# Machine Learning Notebook Archive 📓

A collection of Jupyter notebooks covering data preparation, visualization, and introductory machine learning. The notebooks are separate exercises rather than one installable project.

## Notebook index

- **Fraud data preparation and exploration:** `Falcon Fraud.ipynb`, `Falcon process phase.ipynb`
- **Classification practice:** `KNN_CHECKPOINT.ipynb`, `Logistic-checkpoint.ipynb`, `tree-checkpoint.ipynb`
- **Regression practice:** `checkpoint regression ML.ipynb`
- **Clustering:** `k-means and hierachical.ipynb`
- **Association rules:** `last checkpoint.ipynb`
- **Other practice notebooks:** `python_checkpoint.ipynb`, `VISUALIZATION.ipynb`

Several filenames still say “checkpoint,” and the repository does not include one shared environment or data setup for all notebooks. Review the inputs and dependencies in an individual notebook before running it. This archive is useful as a record of practice; feature the better-documented standalone projects first.
